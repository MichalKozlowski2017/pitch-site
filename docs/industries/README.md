# Playbooki branżowe

Każdy plik opisuje **typowy układ, warianty, ton i FAQ** — nie zastępuje `client.json`, tylko przyspiesza decyzje.

| Plik | Branże |
|------|--------|
| [`beauty.md`](beauty.md) | Paznokcie, fryzjer, kosmetyczka, barber (lokalnie) |
| [`construction.md`](construction.md) | Budowlanka, remonty, hydraulik, elektryk |
| [`_template.md`](_template.md) | Szablon nowej branży |

Po pitchu dopisz sekcję **Pitch: …** na końcu właściwego pliku.
